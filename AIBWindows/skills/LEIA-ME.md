# Skills do AIB

Cada subpasta aqui é uma skill que vem com o AIB, no mesmo formato das do usuário
(`SKILL.md` com cabeçalho `---` e, se tiver, o script).

- Vão junto com o `AIB.exe` (pasta `skills/`) e, a cada arranque, são **espelhadas** em
  `~/.AIB/skills/default/` (`SkillsPadrao`). O que for mudado lá volta ao original; o que não vier
  daqui é apagado. Para mudar uma skill do AIB, mude aqui.
- Nome repetido com uma skill do usuário: vale a daqui.
- Este arquivo, solto na raiz, não é copiado.
- Nada específico de um usuário ou empresa (endereço de portal, ID de pessoa): isso fica nas skills
  do próprio usuário, em `~/.AIB/skills/<pasta>`. Segredo, só pelo cofre (`cofre:` no cabeçalho).

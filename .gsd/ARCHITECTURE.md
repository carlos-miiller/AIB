## Data Flow
1. **User Input:** The user interacts via global hotkeys, voice commands (Whisper.net), or text input in the chat window.
2. **Context Gathering:** The application captures the screen (MSS/OcrService) or reads active window context to understand the user's current task.
3. **Processing:** Requests are sent to OpenAI's API (`OpenAIService` / `openai_client.py`) with the gathered context.
4. **Execution/Response:** The assistant responds via text, voice, or by executing tools (`NativeTools.cs` / `CommandService.cs`).
